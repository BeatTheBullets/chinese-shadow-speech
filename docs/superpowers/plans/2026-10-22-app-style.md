# App-wide style ("Lacquer"), control bar, listen/speak states, Echo + Flow only — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every page one token-driven "Lacquer" look and replace the control bar. Show listen / get ready / your turn as large stage states with a live waveform. Cut the practice modes to Echo and Flow.

**Architecture:**
- A single token module (`src/theme/tokens.ts`) feeds both Tailwind and the code that needs raw colours (canvas, charts).
- A small set of shared UI parts (`src/ui/`) is used by every page: Button with key hint, notched Card, non-modal Popover, and icons.
- Behaviour changes are made where the logic lives today: `Practice.tsx`, `lib/cue.ts`, `lib/karaoke.ts`, `useFlow.ts`, `DrillRunner.tsx`.

**Tech Stack:** React 18, Vite 5, Tailwind 3, vitest 3 + Testing Library, `@fontsource` fonts. Backend touch: FastAPI config only.

**Spec:** `docs/superpowers/specs/2026-10-22-app-style-design.md`. Read it first; §n refers to it. The mockups in `.superpowers/brainstorm/571518-1792687691/content/` are git-ignored but present on this machine at `~/shadow-speech/...`; use them as visual reference:
- `control-bar-v2.html`
- `palette-v2.html`, option A
- `listen-speak.html`

## Global Constraints

- **Tokens, verbatim** (§1.1). Values may be nudged only to reach WCAG AA (4.5:1) for text, keeping the hue:

  | Token | Value |

  | `card` | `#4E001B` |
  | `line` | `#6b1a33` |
  | `fg` | `#f6ead8` |
  | `fgdim` | `#c7a9a0` |
  | `accent` | `#F5CB00` |
  | `ref` | `#d6e6ea` |

  | `sound` | `#cca4e3` |
  | `record` | `#e0301e` |

- **No hex colour literals in components** after Task 1 (`src/**/*.tsx`, excluding tests). `src/anki/listening.ts` is exempt: that is the Anki card's own CSS, inside Anki.
- **Dark only.** No white or light surface anywhere, including dialogs and native `select` and `range` inputs.
- **Notched window-frame corners** (an octagonal clip of 12–14 px) are used only on main cards: the sentence card, lesson tiles and Stats panels/cards. Buttons and chips are rounded at about 12 px.
- **Characters** use Noto Serif SC, bundled locally with `@fontsource/noto-serif-sc`, weights 400 and 600, simplified-Chinese subset. No CDN. All other text uses Inter.
- **Keys:** ←/→ prev/next, Space listen, Enter record/stop, R me, A Anki, S 0.75× toggle, F difficult, T/P/E characters/pinyin/English, L drawer, ? help. **C is removed.**
- **Button labels** say what happens. The key hint is small and grey under the label, never the button face.
- **The play triangle ▶ means "Listen" (the reference).** The speaker icon means sound settings. The chevrons ‹ › mean previous and next.
- **Modes in the UI:** Echo and Flow, with Flow variants *after* and *along*. The `Mode` type and labels keep `chorus` and `guided` for old data. The backend keeps accepting all mode values.
- **Commands** (run from the worktree):
  - Frontend: `cd frontend && npm test -- --run && npx eslint . && npx tsc -b`. One pre-existing Drawer.tsx eslint warning is expected.
  - Backend: `cd backend && PYTHONPATH=$PWD ~/shadow-speech/backend/.venv/bin/python -m pytest -q`. **Never** run `uv run` or `uv sync` in a worktree: the venv is shared with the user's running backend.
  - `npm install` of the new font package is allowed in the worktree only if `frontend/node_modules` is the worktree's own and not a symlink. Otherwise the controller installs it on main first.
- **Commits** end with a blank line and the Co-Authored-By line of the model that writes them.

## Review Focus

- **Keys while the Sound pop-up is open:** Space, Enter, ← and → still act on the page; Esc closes the pop-up. Test: Task 4 `keys still work while the Sound pop-up is open`.
- **Old attempts recorded as Chorus or Guided** (Review list, stored flow runs, Stats) render with readable labels and no crash. Test: Task 3 `old chorus/guided takes still render with their labels`.
- **A persisted settings blob that still holds `chorusPasses`** (zustand `persist`, localStorage) loads without errors. Test: Task 3 `settings with a stale chorusPasses still load`.
- **Recording before the mic exists** (permission prompt, or `mic.open()` returns null): the live waveform shows nothing and does not throw. Test: Task 5 `live waveform without a recorder renders empty`.
- **A Flow gap shorter than the count-in minimum (0.5 s):** no countdown ring appears, as today with no dots. Test: Task 5 `no countdown when the gap is too short`.
